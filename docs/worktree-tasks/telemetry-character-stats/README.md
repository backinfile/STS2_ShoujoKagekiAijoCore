# 对局后台角色统计

## 原始要求

> 新增一个角色统计页，分析各个角色的胜率等信息。 另外 你的语言统计有收到信息吗？ $worktree-task

随任务提供的 $worktree-task 流程见 [user-instructions.md](user-instructions.md)。

### 确认

> 合并上线并清理工作树

## 计划

1. 核对生产对局是否收到游戏语言字段，以及线上接收协议的支持情况。
2. 使用后台现有筛选和统计样本口径，新增角色胜率和对局结果统计。
3. 定向验证历史数据、多人席位、空结果及页面，提交后确认合并、清理及上线安排。

## 结果

- 起始分支为 `main`，起始提交为 `ff1b245`，原检出干净。工作树位于 `../worktrees/STS2_ShoujoKagekiAijoCore/telemetry-character-stats`。
- 新增后台「角色统计」，支持公共筛选、排序及 CSV，展示每个角色的对局数、统计席位、胜率、胜利／死亡／放弃席位和平均楼层。对局数按该角色参与的对局 ID 去重。多人局按各玩家席位计入胜率，默认排除第 5 层及以前放弃的对局。
- 2026-11-21 只读核对生产库，共 2,035 局，其中 689 局携带 Core 上下文，0 局携带语言字段。生产仍使用要求固定字段集合的旧协议，会拒绝带 `language` 的 Core 载荷。仓库已有可选语言字段兼容，发布包包含该兼容。
- 同一生产口径下，全部时间有 88 个角色进入有效样本。华恋 224 胜／620 席位（36.1%），纯那 3 胜／7 席位（42.9%）。纯那另有 4 局在第 5 层及以前放弃。旧记录可参加角色统计，游戏语言归为未知。

## 验证

- 定向 HTTP 用例通过，核对鉴权、多人同角色席位、对局去重、旧无语言记录、提前放弃、语言和角色筛选、空结果。
- 定向语言协议用例及 Web 测试通过，覆盖上传、重试身份、筛选、排序与 CSV。Chromium 使用隔离数据验证 1280 和 390 像素视口、首屏胜率、语言筛选、空结果和 URL 恢复。
- 标准发行包构建通过。以线上当前发行源码准备的定向生产更新保留现行对局事实格式，补入角色统计与语言协议；该组合在本地通过角色统计、语言接收和错误重试的 5 项定向检查。
