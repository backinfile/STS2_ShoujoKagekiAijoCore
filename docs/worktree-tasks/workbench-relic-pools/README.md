# 工作台遗物分类、筛选与展示

## 用户原始要求

> 修改下工作台中的遗物页签 参考卡池中的备用区和垃圾桶修改下

> $worktree-task

> 筛选也加下，另外你来重新调整下遗物展示ui，不要一个遗物一大行，重新设计下

> 合并 清理 部署

## 计划

- 核对卡池分类、移动和恢复交互，沿用工作台样式和保存机制。
- 为遗物增加对应入口，定向验证新旧遗物数据和编辑路径。
- 遗物列表改为多列网格，加入搜索与稀有度筛选，并复验窄屏布局和详情入口。

## 实际变更

- 遗物页侧栏采用卡池的分类控件，提供遗物池、备用、垃圾桶，分类和筛选可通过 URL 打开。
- 编辑栏可将遗物移入备用、移回遗物池或软删除。垃圾桶中的遗物可以查看和恢复，恢复后回到删除前的分类。
- 分类修改使用现有 MCP 字段提交、历史及撤销重做。保留遗物内容、升级关系和初始配置引用。
- 遗物以多列网格展示图标、名称、稀有度和效果摘要。详情保留完整效果、出处和升级关系。
- 可搜索名称、编号、效果和出处，并叠加稀有度筛选。结果区显示匹配件数，重置筛选保留当前分类。
- 使用本地编辑页、只读页和隔离 MCP 数据验证筛选组合、升级关系跳转、归档及恢复、撤销重做、重新载入和共享卡池操作。核对了 320、390、900、1440 像素宽度的网格布局，以及 900 像素宽度打开详情后同排显示两件遗物。
- 已将新版部署到原公开站点及私有编辑入口。隔离副本和正式环境均通过四工作区入口与 MCP 读取检查，浏览器验证线上遗物网格、搜索、稀有度、备用和垃圾桶。
- 正式切换前备份纯那、Core、华恋三份 SQLite，切换后原数据库文件 SHA256 逐一一致。纯那版本为 5929。保留生产备份和上一版程序目录。
- 部署使用提交 fe2905f 的工作台源码，源码归档 SHA256 为 61e466fc79ddccc1786d878115cebbb0aabec91a2f1491085b32dfbd18efb75d。合并前补记部署结果，工作台源码树与已部署版本一致。
