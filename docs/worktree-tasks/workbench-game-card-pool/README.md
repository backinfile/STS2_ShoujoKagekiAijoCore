# 工作台奖励牌池判定

## 原始需求

> 工作台中的入池相关逻辑移除吧，根据游戏内的入池逻辑来判定是否入池，比如说基础牌是玩家起始牌，不会入池

## 计划

- 核对游戏的常规战斗奖励取牌逻辑和纯那的额外奖励筛选。
- 移除手动入池设置，将卡牌列表、总览和流派统计统一接入奖励判定。
- 验证基础牌、关联牌、旧快照和工作台构建。

## 结果

- 工作台按角色卡池和普通、罕见、稀有三个稀有度计算常规奖励候选。基础牌仍显示在初始配置和全部牌面中。全部牌面统计覆盖所选工作台分类中的卡牌。
- 纯那游戏卡牌目录修订 5585 中，额外排除的 14 张常规稀有度牌沿用游戏侧判定。工作台导出仍提供自动计算的 pool 字段，供纯那现有卡牌目录生成器使用。旧草稿和历史记录中的手动值不影响判定。
- 知识组换主牌只更新关联与发放数量。批量删除、备用和移回仍保护组外独立奖励牌。
- 逐张对照本体五职业 439 张参考牌及纯那游戏目录的 102 张牌，奖励候选一致。纯那目录包含 70 张奖励牌。定向 Node 测试 9 项通过，只读版与编辑版构建通过。
