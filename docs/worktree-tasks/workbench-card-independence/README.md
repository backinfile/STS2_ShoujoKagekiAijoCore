# 工作台独立牌操作

## 用户输入

> 工作台中翱翔在天际这张牌，我把描述中的知识关键字去掉，怎么又自动加回来了？

> 添加简单操作设置一张牌完全独立开

> 合并，清理分支，发布

## 计划

- 在卡牌编辑器中提供「设为独立牌」，一次保存双向知识关联、关键词和牌面的变更。
- 验证原问题和撤销流程，合入 Core 主分支，清理本次任务工作树与分支，再发布原址工作台。

## 结果

- `tools/workbench/app.js` 提供操作入口，复用现有编辑事务和撤销历史。
- `tools/workbench/workbench-domain.js` 清除双向关联，包含来自垃圾桶的附带关系。入池由卡牌的入池设置控制。
- `tools/workbench/card-independence.test.cjs` 覆盖双向关系、退役来源、其他附带牌数量和残留标记。
- 本地浏览器用「翱翔在天际」的数据验证了按钮、保存、撤销和重做。
