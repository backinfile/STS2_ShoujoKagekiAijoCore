# 统计表和统计图图片下载

起点为 `main` 的 `090d6c4`，原检出干净。任务工作树位于 `../worktrees/STS2_ShoujoKagekiAijoCore/telemetry-stat-image-export`。

## 原始用户输入

> 工作台中允许以截图形式下载统计表和统计图，注意下载的图中去掉多余的空格等内容，尽量让图片小点

## 简要计划

1. 在对局观察的卡牌统计与对比面板加入图片下载。
2. 按当前显示的表或图生成紧凑图片，保留数据、排序与分组。
3. 在浏览器验证两种下载、筛选后的图片尺寸及对比侧行为。

## 结果

- 对局观察的卡牌统计和对比模式各侧加入「下载 PNG」，导出当前已经加载的统计表或对比图。沿用筛选、排序和分组，保留选牌记录、持有席位、百分比和分母等对应视图的数据。
- 图片按文字和行数确定尺寸，使用紧凑列距，保留 8 像素边距。图片仅绘制数据、表头、分组名和图例。结果为空、正在更新数据或正在生成图片时，下载按钮禁用。
- 仍可通过原有 CSV 下载完整筛选结果。PNG 超过画布尺寸时提示缩小卡牌筛选范围。

## 验证

- 在 Chromium 中使用回环 HTTP 数据与生产 CSP 实际下载 PNG，核对桌面、390 像素视口、独立对比侧、空结果、排序、分组和筛选。测试样例的三行统计表为 490 × 192 像素、18,372 字节，三行对比图为 389 × 238 像素、18,064 字节。筛到一行时对比图为 387 × 126 像素、9,028 字节。
- 查看了两种 PNG 的可见文字、条形图和边距。`node --check web/telemetry/app.js`、`node tools/telemetry/test_web.cjs` 和 `git diff --check` 通过。
