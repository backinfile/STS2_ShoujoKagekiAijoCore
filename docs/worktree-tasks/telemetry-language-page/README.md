## 结果

- 新增独立「语言统计」页，按对局显示语言局数、占比和总样本，支持公共筛选、CSV 和未知语言。多人命中角色筛选后按同一局计一次。
- 将对比模式移到「卡牌统计」内部，保留原有对比链接、左右独立筛选、导出及窄屏切换。
- 后台新增可回填的轻量读索引。角色、语言、来源和版本筛选使用索引，角色页和语言页不读取卡牌明细，卡牌页只解析匹配对局的精简席位记录。上传和事实更新通过 SQLite 触发器同步，已有原始载荷及事实版本保留。
