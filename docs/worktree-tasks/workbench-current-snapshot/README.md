# 工作台公开快照保留

## 原始要求

> ssh vipcloud 看看是不是后台占用磁盘数据有点多？

> **旧版快照**没有用了吧，删除吧

> **新版快照**  也清理下，没有必要存

> 你写个文档说明下，快照只保留一份即可

## 计划

核对线上公开路径，保留当前工作台快照并清理历史快照。在部署文档中记录保留规则与清理顺序。

## 结果

- 线上删除 2,652 份旧版快照、418 份新版历史快照及 3 份更早的静态发布包。发布目录只剩当前快照，可用空间由 16.19 GiB 增至 30.76 GiB。
- 清理后工作台服务处于运行状态，四个公开工作区入口均返回 HTTP 200。
- 在 [工作台部署文档](../../../tools/workbench/deploy/README.md) 记录公开快照只保留一份的规则及清理顺序。暂存检查通过。
